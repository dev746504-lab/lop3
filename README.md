# lop3

Web game tương tác - Kỹ năng tự tin thể hiện bản thân (Lớp 3, Tiết 2).

React (Vite) + Tailwind CSS + Lucide React + canvas-confetti, gồm 4 mini-game:

1. Nạp năng lượng tự tin
2. Hộp quà bí mật - Bắt chước thần thái
3. Nâng cấp chiến binh tự tin
4. Cây tự tin nở hoa

## Chạy thử

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npx vercel --prod
```
